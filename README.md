# Netflix-CH71-

# Clon de Netflix - Proyecto Colaborativo Sala 1

Este repositorio contiene el desarrollo del clon visual de la plataforma de streaming **Netflix**

---

## 📌 1. Plataforma Clonada
* **Plataforma:** Netflix (Streaming)
* **Objetivo:** Replicar la interfaz visual de Netflix aplicando maquetación responsiva, componentes estilizados de Bootstrap  y flujo de trabajo colaborativo con Git y GitHub.

---

## 🛠️ 2. Componentes de Bootstrap Utilizados
En el desarrollo general del proyecto y en la sección asignada se integraron los siguientes componentes y utilidades de **Bootstrap 5**:

1. **Carousel (`carousel slide`):** Implementado para crear el carrusel desplegable interactivo de películas en la sección de tendencias, con botones de control lateral (`carousel-control-prev` y `carousel-control-next`).
2. **Grid System (`container`, `row`, `col-*`):** Utilizado para estructurar el diseño responsivo en pantallas móviles (`col-12`), tabletas (`col-sm-6`) y computadoras (`col-md-3`).
3. **Cards (`card`, `card-img-top`):** Empleadas para encuadrar los pósters de las películas y series de forma limpia y organizada, utilizando clases utilitarias como `bg-dark`, `text-white` y `border-0`.
4. **Navbar & Dropdowns (`navbar`, `dropdown`):** Estructuración de la barra de navegación superior con menú desplegable para el perfil de usuario.
5. **Buttons (`btn`, `btn-danger`, `btn-outline-light`):** Botones de llamada a la acción estilizados al color corporativo de Netflix.
6. **Forms (`form-control`):** Buscador de contenido e insumos de filtrado.
7. **Modal & Accordion:** Componentes para desplegar información detallada e interacción en preguntas frecuentes.
